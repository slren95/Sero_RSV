# RSV Serological Analysis

This repository contains the R scripts and Stan models accompanying the manuscript:

**A second period of increasing respiratory syncytial virus susceptibility from 9 to 24 months revealed through multiplex paediatric serology and Bayesian latent-class modelling**

## Data availability

To protect participant privacy, the raw study data in the `data/` directory are not included in this repository. Consequently, analyses that depend on these data cannot be reproduced from this repository alone.
